# GC10-DET demo examples

These six images are selected from the boxed examples supplied by the project
author for the repository presentation. They were copied without image edits
from the local `isaac_eval_yolo_dataset/annotated_test_images` collection.

Source dataset: [GC10-DET](https://github.com/lvxiaoming2019/GC10-DET-Metallic-Surface-Defect-Datasets).

Dataset paper: [Deep Metallic Surface Defect Detection: The New Benchmark and Detection Network](https://doi.org/10.3390/s20061562), *Sensors*, 2020, 20(6), 1562.

| File | Displayed class |
| --- | --- |
| `crease_1.jpg` | Crease |
| `crescent_gap_1.jpg` | Crescent gap |
| `inclusion_1.jpg` | Inclusion |
| `oil_spot_2.jpg` | Oil spot |
| `punching_hole_1.jpg` | Punching hole |
| `rolled_pit_1.jpg` | Rolled pit |

The green boxes show ground-truth bounding-box annotations, as confirmed by the
project author. The overlays are preserved as supplied. These images illustrate
defect appearance and are not model predictions, a detection benchmark, or a
record of live-run performance.

Dataset credit remains with the original authors. This directory does not assign
a new license to the source dataset.
